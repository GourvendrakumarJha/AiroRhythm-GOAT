    Need a hand?

    The usual snags, and what to do about them. Nothing here can break your fan.

    The AiroRhythm-Setup network doesn't appear+

    1. Power-cycle the fan. Unplug it, wait ten seconds, plug it back in — the setup network only starts when the fan boots without saved Wi-Fi.

    2. Wait for the LED to blink slowly. A slow blink means setup mode is running. Solid means it is already online.

    3. If it still doesn't appear, the board may be running different firmware. Flash firmware/airorhythm_wifi_setup.ino from this repository (Arduino IDE, board “ESP32 Dev Module”).

    My phone says “No internet connection”+

    That's normal. The fan's setup network has no internet — it only exists to pass your Wi-Fi details across.

    On Android, tap Stay connected (or “Keep Wi-Fi on”) when the prompt appears. On iPhone, tap Keep Trying Wi-Fi, or open Settings → Wi-Fi and reconnect to the fan.

    Don't turn on mobile data as a fix — the page needs the fan's network, not the internet.

    It says the password didn't work+

    Wi-Fi passwords are case-sensitive — check capitals and look-alike characters (0 vs O, 1 vs l).

    If you are sure it's right, check the network is 2.4 GHz: the ESP32 has no 5 GHz radio. Many routers broadcast both, with the 5 GHz name ending in 5G.

    Also check the router isn't hiding the network or using “WPA3-only” security — the fan needs WPA2 (WPA2/WPA3 mixed mode is fine).

    My Wi-Fi is 5 GHz only+

    The ESP32 can only join 2.4 GHz networks. Most routers have both — look for a second name in the list (often the same name without “5G”).

    If your router only runs 5 GHz, enable the 2.4 GHz band in the router app, or use a phone hotspot set to 2.4 GHz for testing.

    “Couldn't reach the fan” after setup+

    Make sure your phone is back on your home Wi-Fi — during setup it was on the fan's network, which disappears once the fan joins yours.

    Phone and fan must be on the same network. Guest Wi-Fi and “AP isolation” on the router block device-to-device traffic.

    Recent Chrome versions ask for permission before a page can reach a private address — tap Allow.

    Try http://airorhythm.local (Android and laptops) or the fan's IP address. iPhone can't resolve .local names, so use the IP there.

    The page can't talk to the fan at all+

    Browsers block an https:// page from reaching http:// devices on your network. If this page was opened from a hosted or https address, the fan connection will be refused.

    Use the http:// copy at home: run node connect/server.js on a laptop and open http://localhost:8080, or open index.html directly from disk. The demo works from https because it runs on the same server.

    What do the LED blinks mean?+

    Slow blink — setup mode, waiting for you.
    Fast blink — trying to join your Wi-Fi.
    Solid — connected and online.
    Double blink — it couldn't join; try setup again.

    Start over / factory reset+

    From the Fan tab, open Network → Start over. The fan forgets the Wi-Fi and brings its setup network back.

    No connection at all? Unplug the fan, hold the BOOT button on the board, plug it back in, then release after two seconds. The fan clears its saved Wi-Fi and restarts in setup mode.

    Is this safe?+

    Your Wi-Fi password travels only across your own local network, from this page to the fan, and is stored in the fan's flash memory. There is no cloud account and nothing is uploaded.

    The setup network is open by default so you can join it easily — setup is a two-minute window on your own home network. You can give it a password in the firmware (AP_PASSWORD) if you prefer.

    Still stuck?

    Open the browser console (F12) and copy any message starting with [AiroRhythm] — it will say exactly which address failed.
